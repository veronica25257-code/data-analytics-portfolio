# Dashboard de Revenue Assurance
 
## Objetivo
Monitorear discrepancias entre eventos de red y eventos facturados para identificar fugas de ingresos y evaluar la efectividad de los procesos de conciliación.
 
## KPIs
- Eventos Totales
- Eventos Perdidos
- Ingreso Esperado
- Ingresos Perdidos
- Tasa de Reconciliación
- Tasa de Fuga
 
## Principales Hallazgos
- Reconciliación global: 84.1%
- 7 millones de eventos perdidos.
- Pérdidas estimadas: $310.79K.
- Roaming concentra el 31% de las pérdidas detectadas.
 
## Herramientas
- Power BI
- DAX
- Excel
