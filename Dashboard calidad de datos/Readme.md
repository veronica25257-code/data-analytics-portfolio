# Dashboard de Calidad de Datos
 
## Objetivo
 
Monitorear la calidad de los datos mediante indicadores de completitud, consistencia y validez.
 
## KPIs
 
- Total Registros
- Registros Correctos
- Calidad General %
- Duplicados
 
## Reglas de Validación
 
Un registro correcto debe:
 
- Tener Email válido
- Tener Teléfono válido
- Tener Documento
- Tener Estado válido
- No estar duplicado
 
## Visualizaciones
 
- Calidad por Sistema
- Tipos de Error Detectados
- Distribución Correctos vs Incorrectos
 
## Principales Hallazgos
 
- Calidad General: 65.46%
- CRM presenta la menor calidad de datos.
- Documentos Vacíos representan el principal error detectado.
 
## Herramientas
