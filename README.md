# data-analytics-portfolio
 
Portafolio de proyectos desarrollados con Power BI enfocados en análisis de datos, calidad de datos y revenue assurance.
 
## Proyectos
 
### 📊 Dashboard de Ventas
Análisis comercial con KPIs de ventas, margen, desempeño por producto, ciudad y vendedor.
 
**Herramientas utilizadas:**
- Power BI
- DAX
- Excel
 
### 📋 Dashboard de Calidad de Datos
Monitoreo de calidad de datos mediante indicadores de completitud, duplicidad, consistencia y validez.
 
**Incluye:**
- Calidad General
- Registros Correctos e Incorrectos
- Análisis por Sistema
- Tipos de Error Detectados
 
### 💰 Dashboard de Revenue Assurance
Análisis de conciliación de eventos y detección de pérdidas de ingresos en telecomunicaciones.
 
**Incluye:**
- Tasa de Reconciliación
- Tasa de Fuga
- Eventos Perdidos
- Ingresos Perdidos
- Análisis por Servicio
 
## Tecnologías
 
- Power BI
- SQL
- Excel
- DAX
- Data Analytics
- Data Quality
- Revenue Assurance
 
## Autor
 
Analista de Datos con experiencia en Telecomunicaciones, Revenue Assurance, Reporting y Calidad de Datos.
