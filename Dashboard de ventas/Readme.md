# Dashboard de Ventas
 
## Objetivo
 
Analizar el desempeño comercial mediante indicadores de ventas, rentabilidad y crecimiento.
 
## KPIs
 
- Ventas Totales
- Margen Bruto
- Crecimiento Interanual %
- Unidades Vendidas
 
## Visualizaciones
 
- Evolución de Ventas
- Ventas por Ciudad
- Top Productos
- Top Vendedores
 
## Principales Hallazgos
 
- Identificación de productos con mejor rendimiento.
- Seguimiento de crecimiento anual.
- Monitoreo de desempeño comercial por región.
 
## Herramientas
 
- Power BI
- DAX
- Excel
